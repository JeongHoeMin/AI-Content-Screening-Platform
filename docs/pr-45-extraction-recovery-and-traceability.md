# PR-45 추출 복구와 실행 추적성

## 목적

OpenAI 이벤트 추출의 일시적 배치 실패가 후보 누락으로 이어지는 일을 줄이고, 원문·프롬프트·비밀값을 기록하지 않는 범위에서 실행 결과를 배치·기사·이벤트·정책 판단 단위로 추적한다.

## 결정

1. Extractor는 실패한 원래 배치를 한 번 재시도한다. 재시도도 실패하면 해당 배치를 더 작은 배치로 나누어 한 번씩 복구한다. 성공한 sibling 결과와 입력 순서는 보존하며, 복구 호출 횟수는 설정값으로 제한한다.
2. `ExtractionError`에는 원래 배치 번호, 시도 번호, 기사 수를 포함한다. 오류 메시지는 기존처럼 provider error type 또는 제한된 structured-response reason만 사용한다.
3. Extractor는 structlog로 배치 시작·성공·실패·재시도·분할 복구와 item parser 제외를 남긴다. Workflow는 추출 결과·후보 제외 사유·최종 후보 수를 안전한 집계와 제한된 식별자로 남긴다.
4. 원문, 제목, URL, 프롬프트, raw SDK response, API key, 예외 전문은 로그에 기록하지 않는다. 이는 `PROJECT_GUIDE.md` 및 ADR-009의 보안 경계를 유지하기 위한 범위 제한이다.
5. 복구 루프는 원본 배치 번호/전체 배치 수, 대상 기사 수, 현재 시도/최대 시도, 분할 크기와 남은 복구 호출 한도를 진행 이벤트로 보고한다.

## 검증 계획

- extractor 단위 테스트로 transient batch 재시도 성공, 재시도 후 분할 복구, 복구 한도, 오류 추적 필드를 검증한다.
- 안전 로그 테스트로 허용된 필드와 금지된 기사 원문 미포함을 검증한다.
- 관련 workflow/dashboard 회귀 테스트와 compileall, diff check를 실행한다.
