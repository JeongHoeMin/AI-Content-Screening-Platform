# 투자 테마·뉴스 주제 수집 필터 구현 계획

> **에이전트 작업자용:** superpowers:executing-plans로 단계별 실행한다. 각 단계는 체크박스로 추적한다.

**목표:** 반도체·AI·대체에너지 같은 투자 테마와 뉴스 주제를 함께 선택하여 조건을 만족하는 문서만 추천 분석에 전달하고, 실행 조건을 재현 가능하게 저장한다.

**아키텍처:** immutable CollectionFilter와 버전 관리 InvestmentThemeCatalog가 선택 조건과 문서 일치 여부를 결정한다. Dashboard Harness는 정규화 뒤 필터를 적용하고 허용 문서만 기존 Evaluator/Workflow로 전달한다. DB 저장은 Harness-owned repository만 수행하며 Provider·Parser·Policy·Workflow는 DB를 직접 호출하지 않는다.

**기술 스택:** Python 3.11, Pydantic v2, FastAPI, SQLAlchemy async, Alembic, PostgreSQL, pytest, Docker Compose.

## 전역 제약

- 사용자 시간과 기준일은 항상 Asia/Seoul이고 DB에는 UTC 시각을 저장한다.
- 설계·목표·계획·운영 문서는 한국어로 작성한다.
- 투자 테마는 개별 기업이 아니라 종목군이다. 초기값은 반도체, AI, 대체에너지다.
- LLM은 테마/주제 필터나 최종 추천을 결정하지 않는다.
- 기사 원문, 프롬프트, secret, raw provider 응답은 로그·SSE·filter audit에 넣지 않는다.
- 빈 필터는 기존 전체 수집 동작과 하위 호환되어야 한다.

class InvestmentTheme(str, Enum):
    SEMICONDUCTOR = "semiconductor"
    ARTIFICIAL_INTELLIGENCE = "artificial_intelligence"
    RENEWABLE_ENERGY = "renewable_energy"


class NewsTopic(str, Enum):
    EARNINGS = "earnings"
    POLICY = "policy"
    SUPPLY_CHAIN = "supply_chain"
    TECHNOLOGY = "technology"


class CollectionFilter(BaseModel):
    model_config = ConfigDict(frozen=True)
    themes: tuple[InvestmentTheme, ...] = ()
    topics: tuple[NewsTopic, ...] = ()
~~~

DefaultThemeCatalog는 각 enum의 한국어/영문 산업어·제품어·대표 기업 alias를 frozenset[str]로 선언한다. 문자열은 소문자화와 공백 정규화만 한다. 두 차원이 모두 있으면 두 조건이 참일 때만 허용하고, 빈 filter는 항상 허용한다.

async def test_repository_round_trips_filter_snapshot(session: AsyncSession) -> None:
    repository = SqlAlchemyCollectionFilterRepository(session)
    stored = await repository.store(
        CollectionFilter(themes=(InvestmentTheme.SEMICONDUCTOR,)),
        catalog_version="themes-v1",

## 구현 기록

### 2026-08-05 (KST)

- 테마·뉴스 주제 catalog, Article filter, 대시보드 다중 선택 UI를 구현하고 단위·대시보드 회귀 테스트로 확인했다.
- 조건 snapshot은 동일 조건 재사용 대신 dashboard run ID를 primary key로 저장한다. 같은 조건의 서로 다른 실행은 이후 LLM 결과·가격·재시도 이력과 각각 연결되어야 하기 때문이다.
- snapshot에는 선택 enum, catalog version, 수집/통과/제외 집계와 UTC 시각만 저장한다. 기사 원문·URL·prompt는 저장하지 않는다.
- 구 migration의 `metadata.create_all()`과 호환하도록 새 migration은 table 존재 여부를 확인한 뒤 생성한다.
